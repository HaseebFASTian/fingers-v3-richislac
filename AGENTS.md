# Richislac standalone website

Work only in this independent Richislac project. GitHub repository and Cloudflare Pages project: fingers-v3-richislac, branch main. Local server port 5178. Preserve sibling websites.

Follow the client's Zesta video/image reference: oversized condensed headings, a bottle-drop/splash hero, scalloped section transitions, circular pack previews, three outlined product cards, annotated bottle composition, lifestyle photography and a large illustrated footer. The Richislac logo sets the palette: royal blue, navy, dairy ivory, sunshine yellow and grass green. No pink/red/purple theme.

Approved source is page 3 of CATALOGUE 5 FINGERS.pdf. Exactly three products: Full Cream Milk Bottle 1 L, Full Cream Milk Gable Top 1 L, Whey Protein Drink 250 ml. Do not invent flavours, prices, discounts, reviews, certifications or delivery guarantees. Product illustrations must retain catalogue branding. Enquiry is a clearly labelled local preview; no fake message submission.

Use native Web Animations and transform/opacity only. Respect reduced-motion, provide a pause control, avoid scroll locking or scroll hijacking. Mobile needs compact cards, 44px targets, a native dialog drawer, safe-area bottom navigation, no horizontal scrolling. All assets and fonts are local.

Run npm run check and npm run build; visually inspect desktop/mobile, motion and reduced-motion, drawer, product details, saved list and enquiry preview. Deploy explicitly to fingers-v3-richislac.
